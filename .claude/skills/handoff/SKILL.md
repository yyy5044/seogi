docs/progress.md를 현재 작업 상태로 갱신한다. 파일이 없으면 새로 만든다.

## 절차
1. `git status`와 `git log --oneline -10`으로 실제 변경 내역을 확인한다
2. 이번 세션의 대화 내용과 1번 결과를 바탕으로 아래 형식대로 파일 전체를 다시 쓴다
3. 갱신한 뒤, 바뀐 내용을 세 줄 이내로 요약해서 보고한다

## 형식
- 목표: 지금 만들고 있는 기능 (한두 줄)
- 완료: 항목마다 확인 방법을 함께 적는다 (통과한 테스트 이름, 커밋 해시)
- 진행 중: 어느 파일의 어느 부분까지 했는지, 어디서 멈췄는지
- 다음 할 일: 우선순위 순서로 번호를 매긴다
- 결정과 이유: 무엇을 선택했고 왜 그랬는지
- 시도했다가 실패한 것: 방법과 실패한 이유

## 규칙
- 직접 실행해서 확인하지 못한 것은 "완료"가 아니라 "진행 중"에 적는다
- 추측으로 채우지 않는다. 모르는 것은 "미확인"이라고 적는다
- 새 세션은 이 파일만 읽고 작업을 이어간다. 대화 내용을 모르는 사람이 읽어도 이해되게 쓴다
- 이미 끝나서 다음 작업에 영향이 없는 오래된 항목은 지운다
