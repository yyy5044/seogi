# experiments — 실험 기록

회의록 파이프라인을 만들면서 무엇을 쓸지, 어떤 옵션을 켤지 정하기 위해 한 실험들. 파이프라인 본체가 아니며 회의록 생성에는 쓰이지 않는다.

## 규칙

- **실험 하나에 폴더 하나.** 그 실험에 썼던 스크립트와 보고서를 같은 폴더에 둔다.
- 스크립트는 **실험 당시 상태를 그대로 보존**한다. 루트 코드가 나중에 바뀌어도 여기 있는 것은 고치지 않는다. 나중에 동작하지 않아도 상관없다. "그때 무엇으로 측정했는가"의 기록이 목적이다.
- 보고서에는 표본, 설정, 측정한 사실, 한계, 결론을 적는다.
- 인식 결과 텍스트와 정답 원고는 회의 원문이라 저장소에 올리지 않는다 (`runs/`, `recordings/`는 gitignore).

## 실험 목록

| 폴더 | 실험 | 결론 |
|---|---|---|
| [stt_compare/](stt_compare/) | 다글로 vs 네이버 CLOVA Speech 인식률 비교 (2026-09-25) | CER 10.7% vs 14.4%, 유의미한 차이 없음. 다글로 유지 |
| [keyword_boost/](keyword_boost/) | 다글로 키워드 부스팅 효과 (2026-09-25) | 켜면 CER 10.7% → 12.7~15.5%로 악화. 파이프라인에 넣지 않음 |

테스트는 루트에서 `py -3.12 -m unittest`를 돌리면 함께 실행된다 (`__init__.py`가 그 용도).
