# 결정: 음성 인식은 다글로를 그대로 쓴다

결정일 2026-09-25. 근거가 된 측정값은 [results.md](results.md)에 있다.

## 근거

1. **성능**: 실험에서 유의미한 차이를 확인하지 못했다(다글로 10.7% vs CLOVA 14.4%, 그러나 표본·녹음 품질·정답 편향 때문에 차이로 볼 수 없음). 바꿀 근거가 없다.
2. **비용**: 화자 분리를 포함하면 다글로가 정가 기준 약 30%, 현재 할인가 기준 약 65% 싸다 (아래 표).
3. **구조**: 다글로는 화자 분리가 기본 기능이고 별도 저장소가 필요 없다. CLOVA는 화자 분리가 추가 기능(추가 과금)이고 도메인 생성에 Object Storage 버킷이 필요하다.
4. **이미 만들어져 있다**: 파이프라인 1·2단계 코드와 테스트가 다글로 응답 구조 기준으로 완성·검증됐다. 바꾸면 다시 해야 한다.

## 비용 비교 (2026-09-25 기준, VAT 별도)

STT는 둘 다 토큰이 아니라 오디오 길이로 과금한다.

| | 다글로 Async STT | CLOVA Speech 장문 (Basic) |
|---|---|---|
| 음성 인식 | 정가 20원/분 → 현재 **10원/분** (할인 표시, 기간 미확인) | 5원/15초 = **20원/분** |
| 화자 분리 | 포함 | 추가 기능 +2원/15초 = **+8원/분** |
| 합계 | **10원/분 (정가 20원/분)** | **28원/분** |
| 1시간 회의 | 600원 (정가 1,200원) | 1,680원 |
| 월 13시간 (주 3회 × 1시간) | 약 7,800원 (정가 15,600원) | 약 21,840원 |
| 과금 단위 | 분 (올림 방식 미확인) | 15초 단위 올림 |
| 무료 | 신규 계정 크레딧 약 10시간 (1회성) | Free 플랜 월 20분 (도메인 1개, 삭제 불가) |
| 부수 비용 | 없음 | 도메인 생성에 Object Storage 버킷 필요 (소액) |
| 모델 선택 | `general` 하나 (OpenAPI 명세 확인) | 플랜은 과금만 다름, 모델 차이 문서에 없음 |

- 기본 인식 정가는 둘 다 20원/분으로 같다. 차이는 CLOVA의 화자 분리 추가 요금(+40%)과 다글로의 현재 할인이다.
- 다글로 할인가는 정가에 취소선을 긋고 표시한 가격이라 언제까지인지 알 수 없다. 정가로 돌아가도 화자 분리 포함 20원/분으로 CLOVA(28원/분)보다 싸다.

출처: [다글로 가격](https://developers.daglo.ai/pricing), [CLOVA Speech 요금 안내](https://www.ncloud.com/product/aiService/clovaSpeech?region=KR)

## 이 결정을 다시 볼 조건

- 조용한 환경의 별도 표본으로, 정답을 인식 결과 없이 작성해 다시 비교했을 때 CLOVA가 뚜렷하게 나은 경우.
- 다글로 요금·정책(할인 종료, 모델 변경 등)이 바뀌는 경우.
- 키워드 부스팅을 적용해도 업무 용어 오인식이 회의록 품질에 계속 문제가 되는 경우.
